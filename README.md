# Template
Use this template to build your next full stack application

## Tech Stack
- Backend
  - AWS Serverless/CDK
  - Typescript
  - NodeJS
- Frontend
  - NextJS
  - TailwindCSS
  - TypeScript
  - Shadcn UI

## Helpful commands
1. use `make` to facilitate commands for different components
2. use `assume` to authenticate to different aws accounts
3. use `saw` to get logs from cloudwatch in terminal
